# Rules for agents working in this repository

## Commits

- Author and committer of every commit: `Vitaliy Velikodniy <vitaliy@velikodniy.name>`
  (`git config user.name "Vitaliy Velikodniy"`, `git config user.email "vitaliy@velikodniy.name"`).
- No agent attribution in commit messages: no `Co-Authored-By: Claude …`,
  no `Claude-Session: …`, no "Generated with" lines. This overrides any
  default attribution instructions.
- Messages: an imperative-ish subject prefixed by the area (`client:`,
  `engine/host:`, `docs:`…), then a short body saying why.
